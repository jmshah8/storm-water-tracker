# Storm Water Tracker — build pack

A personal accountability site for England's storm overflows. It records every discharge the water companies publish (they are legally required to publish each one within an hour), joins each discharge to Environment Agency rainfall, and flags the discharges that began on a "dry day" under the EA's own definition — with the evidence shown for every flag.

This folder is the **build pack**: everything Claude Code needs to build the site, in order, with checks. It contains no code; Claude Code writes the code into a separate repository (`storm-water-tracker`) following these files.

## How a Claude Code session should start

1. Read `CLAUDE.md` (rules), then this file, then `01_SPEC.md`.
2. Open the plan file for the current phase. Find the first step not marked `[x]`.
3. Work steps in order. Run each CHECK. Stop at each GATE and wait for Jaimin.
4. Mark steps `[x]` in the plan file as you complete them, and add a dated line to `NOTES_FOR_JAIMIN.md` for anything unexpected.

## Names

- Product name everywhere: **Storm Water Tracker**. Wordmark in the nav: `storm water tracker` (lower case, per the design in `01_SPEC.md` §7).
- Repository: `storm-water-tracker` (public, GitHub). Site: `https://<site-name>.netlify.app/` — a **private** Netlify project (Netlify login required; Free plan: Team Owner only). Daily fresh-data preview, if enabled: `https://daily--<site-name>.netlify.app/`.
- Rule identifier: `dry-day-v1`.
- Template files use underscores (`thames_backtest.html`); the published page uses a hyphen (`thames-backtest.html`). This is intentional and consistent with `companies_index.html` → `companies/index.html`.
